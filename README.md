# Octane UI

A lightweight component library for [Octane](https://octanejs.dev). Components wrap native HTML elements rather than rebuilding them, keeping the surface small and familiar.

Docs and examples: [octaneui.dev](https://octaneui.dev)

## Packages

- **[`@octaneui/core`](./packages/core)** — UI components and styles
- **[`@octaneui/icons`](./packages/icons)** — framework-native icon sets (Lucide)
